# Sidebar Colors & Typography (MongoDB Style)

## Color Palette (MongoDB-adapted)

| Token | Hex | Usage |
|-------|-----|-------|
| `neutral-50` | `#F8F9FA` | Sidebar background (default) |
| `neutral-100` | `#F1F5F9` | Hover state background |
| `neutral-200` | `#E2E8F0` | Divider/border color |
| `neutral-500` | `#64748B` | Secondary text (muted) |
| `neutral-900` | `#1E293B` | Primary text color |
| `base-blue` | `#016BF8` | Primary accent: active, hover, focus |

## Typography

- **Font Family:** `Euclid Circular A`, `system-ui`, `sans-serif`
- **Base Size:** 14px (4px baseline grid)
- **Active Size:** 16px for emphasized items
- **Weight:** 400 (regular), 500 (medium)
- **Line Height:** Vertical spacing adheres to 4px baseline grid
